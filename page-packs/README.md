# Take 3 — page-by-page review packs

One document per page of the website. Each one lists every word on that page,
every photo slot, what the page is for, who it is talking to, and which kind of
review belongs on it — with space to write notes against each section.

There are three things in this folder, for three different jobs:

- **The review packs** (the files listed below) — every word currently on each page, with room
  to note what you would change. Use these to react to what is there.
- **`worksheets`** — the same pages with all the words taken out, so you can write your own
  version from scratch. Start at `worksheets/index.html`. Use these to write, not react.
- **`live-pages`** — the real pages as they look today, saved to open offline. Start at
  `live-pages/browse.html`. Use these to see the design.

If you are handing this to someone for the first time, point them at the **worksheets**. A blank
page in their own words is worth more than notes in the margin of ours.

## The quickest way to get going

1. **Open `index.html`** (this page) in a browser and click through to the page you have been given.
2. **Open the live page next to it** — the address is at the top of every pack. Seeing the real
   page while you read the words is the whole point.
3. **Get it into something you can type in.** In the browser: select all, copy, then paste into
   a new Google Doc or Word document. Headings, tables and the note boxes all survive the paste,
   and you can leave comments the normal way. One document per page keeps it clean.
4. **Write in the note boxes** under each section, and fill in the "would you change it?" column
   in the photo tables.

If you would rather not use Google Docs, the matching `.md` file is the same content as plain
text and opens in anything.

## If you want to redesign a page rather than just reword it

Two good options, depending on how far you want to go:

- **Screenshot straight into Canva.** Open the live page, take a full-page screenshot
  (in Chrome: right-click → Inspect → Cmd+Shift+P → type "screenshot" → "Capture full size
  screenshot"; on a Mac, Shift+Cmd+4 grabs any part of the screen). Drop that image into a
  Canva design, lock it as the background, and draw over the top — move blocks around, swap in
  a photo you prefer, retype a headline. It is the fastest way to say "this would look better
  like *this*".
- **Sketch it and describe it.** A rough drawing plus a sentence in the note box works just as
  well and takes two minutes. Nothing needs to be pretty to be useful.

Either way, send back the document plus any images. Nothing you do here can break the website —
the real pages only change once someone deliberately makes the change.

## What to look for

- **Does it sound like us?** Confident, plain, no fluff. Read it aloud — if you would not say it
  on the phone to a producer, flag it.
- **Is it true?** Numbers, credits and claims all need to be right.
- **Is anything missing?** A question a client or artist would ask that the page does not answer.
- **Photos.** Every pack lists the pictures in place and the empty slots waiting for one. Say what
  should go in each — a specific shoot, a production, a type of shot.
- **Reviews.** Each pack says whether the reviews on that page should be clients talking about us,
  or artists talking about being represented. If you know the right person to ask for one, say so.
