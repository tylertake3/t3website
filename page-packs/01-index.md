## What this page is for

The front door. Establishes what Take 3 is, the scale behind it, and points visitors to the right talent page within one screen.

**Who it is talking to:** Clients — producers, casting directors, production co-ordinators

**Reviews on this page:** CLIENT reviews — productions, choreographers and casting directors talking about working with the agency. These are pulled from the shared review library, so a change here changes them everywhere they appear.

**Photography:** 2 empty photo slots on this page — grey boxes waiting for a real picture. They are named in the sections below.

## How to use this document

Open the live page alongside this, and work down the sections in order — they are in the
same order as the page itself. Every word on the page is here. Type your notes straight
into the boxes, or use comments if you are in Google Docs.

- **Copy** — reword anything in the quoted lines. Keep roughly the same length unless you say otherwise.
- **Photos** — every photo slot is listed with its file name. Say what you would put there instead.
- **Design** — if a section would work better as something else, describe it or sketch it. Nothing here is fixed.
