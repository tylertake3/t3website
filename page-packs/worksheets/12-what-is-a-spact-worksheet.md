## Read this bit first

This is a blank version of the page. Every place the page has words, there is an empty box
here for you to write your own.

**You do not need to know anything about websites to fill this in.** You know what productions
ask for and how we actually work — that is the whole skill needed here. Write it the way you
would say it to a producer on the phone.

Six things to hold on to:

1. **Write your version, not a correction of ours.** We will take the best of what comes back.
   Do not worry about matching what is there now.
2. **Plain words win.** If you would not say it out loud, do not write it. No "bespoke
   solutions", no "passionate about excellence".
3. **The lengths are a guide, not a rule.** Each box says roughly how long it should be so it
   fits on the page. Go over if you have something better to say — we can make it fit.
4. **Skip anything you are unsure about.** A half-finished worksheet is genuinely useful. Blank
   boxes tell us where the page is confusing.
5. **Cross things out.** If a whole section should not exist, tick "remove it" and move on.
   Saying what to cut is as valuable as writing new words.
6. **Add anything missing.** There is space at the end of every section, and at the end of the
   document, for sections that are not there at all yet.

If you would rather do it in Google Docs or Word: open the `.html` version of this file in a
browser, select everything, copy, and paste it into a blank document. You can then type
straight into it.

## Reviews on this page

**What this page needs:** None — this is an explainer, not a sales page.

There are two kinds and they do different jobs:

- A **client review** is a production talking about working with us. It makes another production
  trust us with a booking.
- An **artist review** is a performer talking about being represented by us. It makes another
  artist want to join the roster.

Who should we be asking, and what would you want them to say? Names are enough — we will chase
