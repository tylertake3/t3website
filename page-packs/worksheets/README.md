# Write your own version of the site

One blank worksheet per page. Same sections as the real page, all the words taken out, with a
box under each one for you to write your own.

## You do not need to be a designer

Everything in here is a question about talent, productions and how we work — not about
websites. If you book artists for a living you already know the answers.

## How to do it

1. **Take one page.** Not the whole site. One page is about half an hour.
2. **Open the real page first** so you can see what it currently does. Every worksheet links to
   it at the top, and there is a saved copy in the `live-pages` folder that works offline.
3. **Open the worksheet.** Use the `.html` file if you want to type into it: open it in a
   browser, select all, copy, paste into a blank Google Doc or Word document.
4. **Answer "First, the whole page" before anything else.** Who is reading it, what should they
   do next, what must they take away. The rest gets much easier once those are down.
5. **Work down the sections.** For each one: keep it, move it, or bin it — then write your version.
6. **Do not stall on a box.** Skip it. Blanks tell us where the page is unclear.
7. **Finish with the missing sections.** What do you explain to people over and over that the
   page never mentions? That part is worth more than all the rewriting.

## What happens to it

Send it back and we take the best of it. Nothing you write goes straight onto the website, so
there is no way to get it wrong — a rough answer in your own words beats a polished one that
sounds like everybody else.

## If you only have time for one

**Join the roster** and **Our artists** are the two that need the most work — both are half
written, and both are aimed at performers rather than productions, so they need a completely
different voice from the rest of the site.

## One more thing worth asking yourself

Every worksheet asks whether that page should have pages underneath it. Please answer it. The
site can have as many pages as it needs, and the pages we are missing are usually the ones
somebody on the phone asks for every week.
